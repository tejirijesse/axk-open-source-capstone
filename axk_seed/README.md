# AXK seed dataset: synthetic five-year history (Sep 2021 to Sep 2026)

> **Synthetic data.** Everything in `data/` was generated by `generate_axk_seed.py`. It is not real trade
> data, not pilot data and not research evidence. Every person, cooperative and business in it is fictional,
> and every transaction hash in it is made up. The importer tags each row `axk_synthetic_seed = 1` and every
> screen that shows it says so.

The dataset exists so the explorer's history charts and hash-chain verifier have something internally
consistent to display. Every record references real records upstream, every Verification Event is
hash-chained to the previous event on its lot, and every settled order has a completion time.

| DocType | Records | What it is |
|---|---|---|
| Cooperative | 42 | Fictional Rwandan cooperatives across 17 districts, each tied to a corridor |
| Harvest Record | 3,400 | Farmer-level intake (member no., plot, kg, moisture, season) |
| Lot | 646 | 1–9 harvest records aggregated, graded, priced, hashed |
| Verification Event | 5,258 | 4–10 events per lot, SHA-256 hash chain from cooperative intake to buyer receipt |
| AXK Order | 549 | Fictional cross-border and Kigali sales with FX and settlement channel |
| Escrow Contract | 176 | Fictional escrows with made-up fund/release/refund hashes |

```
generate_axk_seed.py           deterministic generator (seed 20260929)

```

## Loading it

The dataset is stored in DocTypes that belong to AXK Network's platform app, which is not open source. See
[docs/history-dataset.md](../docs/history-dataset.md) for why it is optional and how roadmap item PUB-4 makes
it loadable on a plain Frappe site. With the platform app installed:

```bash
make seed         # import, tagging every row as synthetic
make seed-purge   # remove only the synthetic rows
```

## What the synthetic data illustrates

These are properties the generator was written to have. They are **not findings** and must not be reported
as evidence about real trade.

- **Tamper evidence:** `Verification Event.prev_hash` → `event_hash` chains verify from a `0000…` genesis
  for all 646 lots (the generator asserts this). Change one field and the chain breaks.
- **Corridors:** Rubavu–Goma, Rusizi–Bukavu, Cyanika, Gatuna/Katuna, Kagitumba, Rusumo, plus a domestic Kigali
  baseline, with CDF, UGX, TZS, RWF and USD amounts.
- **Shape over time:** volumes grow year on year and the settlement-channel mix shifts toward escrow, so the
  charts have a trend to draw. The trend is an input to the generator, not a measurement.

## Generator assumptions

- Prices: a 2021 base RWF/kg, scaled by an annual inflation index, a seasonal factor and the grade.
- Seasons: A (Jan–Mar harvest), B (Jun–Aug), C (marshland, Sep–Oct).
- Moisture tolerances per commodity; lots above tolerance are graded C or rejected.

## Regenerating

```bash
python3 generate_axk_seed.py       # stdlib only, about 2 s
```

`YEAR_WEIGHT` changes the growth curve, `N_HARVEST` the volume and `SEED` gives a different but equally
consistent history.
